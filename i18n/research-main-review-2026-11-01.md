## value-indexed-memory-persistent-traversal

- 原题：Retrieval as Traversal: Value-Indexed Memory for Stateful Long-Context Agents。
- 作者：Daniel Strauß、Zhenshan Bing、Alois Knoll。
- [原始摘要与提交记录](https://arxiv.org/abs/2610.40545v1)：首次提交2026-10-29 17:37:21 UTC。作者注明获 NeurIPS 2026 Workshop on Long-Context Foundation Models 接收；类型为会议论文，明确工作坊及作者注明。
- [固定版本全文](https://arxiv.org/html/2610.40545v1)：§1 动机和贡献边界，§2 价值索引目标与互补/冗余推导，§3 固定空间概念实验及表1、负面对照，§4 未解决问题，§5 结论。
- 主方向理由：核心是 Agent 记忆的持久检索位置、相对寻址和学习效率，属于 Agent 记忆机制，而非只在应用中提到 Agent。
- 机制：区分记忆内容和地址；按任务效用衡量信息增量，同时惩罚每条局部可访问记忆，避免所有地址坍缩到同一点。互补信息适合共同获取，纯冗余信息会多付检索成本。理论目标和实验实现必须区分：论文没有给出完整的价值索引空间训练方案。
- 实验：MiniGrid Memory；Transformer-XL 与 PPO；先在64个上下文位置的固定任务预训练，再在5个位置的随机任务适应。所需线索早于决策7—17个环境步骤。地址直接来自空间和时间坐标；没有训练所提价值索引。三种检索头各六个种子，短上下文无检索头基线三个种子。
- 表1：跨种子平均回报曲线达到0.95的训练步数，相对移动0.59M、高斯绝对寻址0.94M、类别绝对寻址在2.048M预算内未确定达标。0.95是回报，不是准确率；该统计不是对单种子达标时间求平均。
- 重要反例：短上下文无检索头 Agent 也能通过等待时间或转向行为保存线索，合法完成任务。因此只能说学习/行为效率改善，不能声称拥有基线没有的能力。
- 限制：只需检索一条关键信息；没有验证连续多次记忆检索、学习的地址几何、低变化检索假说。上下文依赖的互补与冗余能否在固定空间表达仍未解决。不能写成已证明真实大模型长上下文加速或取代语义检索。
- 内容筛选：研究目标和小规模实验证据可核验，非产品宣传，无广告导购及色情、赌博、毒品性质内容或引流。

## prefix-executability-tool-agent-reliability

- 原题：Prefix Executability: Evaluating Tool-Using Agents Beyond Final Success。
- 作者：Amir H. Rezaeian、Weiyi Sun、Yassine Benajiba、Dan Roth。
- [原始摘要与提交记录](https://arxiv.org/abs/2610.40444v1)：首次提交2026-10-29 16:58:04 UTC。作者注明 Accepted to NeurIPS 2026，但没有轨道。会议元数据保留 author-reported acceptance; track unspecified，不记为独立核实主会录用。
- [固定版本全文](https://arxiv.org/html/2610.40444v1)：§2 指标、确定性评分器及实验协议；§3 表2、迁移边界；Limitations；正文引用附录C/F的检查与敏感性说明。
- 主方向理由：直接评估工具 Agent 的过程可靠性、依赖和状态前提，并研究执行前验证，属于 Agent 评测与可靠性。
- 指标核实：基准评分器使用确定性状态检查，不是模型裁判；试验中的模型计划验证器是另一机制。首次拒绝确定FED，前缀重放停止，完整执行仍用于最终成功与恢复评分。TER以全部执行为分母；恢复率只以出现过非法前缀的执行为分母。固定全样本PEC随深度下降可来自错误或正常提前终止，不能写成纯错误率。归一化面积按各执行自身长度计算。
- 实验范围：BFCL-v3与ToolSandbox各200任务，三模型四方式形成4,800执行；τ³-bench航空50题、零售114题基本集合形成1,968执行，总6,768。每条件每任务一次，不代表重复种子波动；主表边际区间不能据重叠判断配对显著性。
- 精确分母示例：BFCL/Llama-4 Maverick计划约束方式200执行，10条全程可执行且成功；190条有非法前缀，其中138条后来成功。TER=10/200=5%，恢复率138/190约72.6%，最终成功148/200=74%，成功中138/148约93.2%曾有错误。三者并不矛盾。
- ToolSandbox/GPT-5.4：计划约束最终成功点估计69%，Dual-Loop为63%；TER从48%升至94%。因此不能称验证方案全面提高成功率，必须分清过程指标和终点收益。
- 迁移和限制：τ³-bench没有建立前两组一致的验证优势；独立配对敏感性研究的TER及面积变化95%区间均含零。方法依赖明确前提和可见状态，未评估匹配的约束解码基线；验证与额外推理/上下文效应未完全分离。合法执行仍可能语义错误或违背意图，不是完整正确性证明。
- 内容筛选：可核验方法、样本及结果，非品牌稿；无广告促销或色情、赌博、毒品性质内容与推广。公开正文只解释工具依赖概念，不包含私人系统信息或操作片段。

## on-policy-state-training-multihop-retrieval

- 原题：Retrieving from Your Own Mistakes: On-Policy Training of Embedding Models for Multi-Hop Retrieval-Augmented Generation。
- 作者：Chenjie Qiu、Zixuan Zeng、Shaobin Shi、Bingfeng Chen、Dongsheng Luo、Boyan Xu。
- [原始摘要与提交记录](https://arxiv.org/abs/2610.40409v1)：首次提交2026-10-29 16:40:02 UTC，没有列出会议录用证据，分类为preprint；不据arXiv托管本身推断评审状态。
- [固定版本全文](https://arxiv.org/html/2610.40409v1)：§3 链式检索与污染状态定义，§4 逐轮状态训练，§5 数据、表1—4及恢复探针，§6 结论范围。
- 主方向理由：核心是多跳RAG证据检索、检索错误传播和学习恢复，直接属于RAG方法。
- 机制：每轮让当前检索器收集真实访问状态，与标准历史各占一半；访问状态每轮替换。目标为最早尚缺的正确证据，其他尚缺正确证据不当负例。只更新查询编码器低秩适配，文档索引固定，负例由固定编码器按相同规则选择。使用已有证据标注，不需要模型裁判或最终奖励，不能写成无监督或不需要标注。
- 训练及分母：MuSiQue训练1,800问、验证200问；测试1,000个官方开发集问题，语料11,656篇。C@5是问题级全部正确证据进入前五的比例，不是单篇召回。
- 表1五种子：方法C@5=49.3%，Search-R1=36.5%。同架构同预算的表3单种子消融，标准历史44.6%→当前访问状态50.5%；五种子主结果与单种子消融不混用。绝大部分相对冻结编码器的收益来自链式训练本身，状态训练增量需看匹配对照。
- §5.4固定3,403个仍缺证据状态的探针：含一个错误文档子集的下一步正确检索25.0%→35.8%，两个以上子集14.5%→29.2%；分母分别为相应状态子集，而不是全部3,403。表2同阅读模型取各检索器前五篇，单种子方法答案完全匹配44.1%，Search-R1的材料35.5%，是作者报告的下游结果。
- 迁移：作者构造HotpotQA-Long和2Wiki-Long，各300问，语料554,812及220,000篇，不额外训练。前十篇完整覆盖29.6%/32.8%；Search-R1在2Wiki-Long为37.0%，不能写成全面领先。四跳MuSiQue完整覆盖依然较低。
- 边界：消融、探针、下游问答单种子；长链是作者构造集合，不等同原始标准集。两个图检索基线在长链使用缩小语料，其他模型规模和搜索预算不同；跨系统差距不能全归因新训练方法。同检索器匹配对照及每轮刷新分析是更有力证据。
- 内容筛选：有明确检索方法和可定位实验，不是品牌宣传；排除广告、促销导购及色情、赌博、毒品性质内容或引流。
