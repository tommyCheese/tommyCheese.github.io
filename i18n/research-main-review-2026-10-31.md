## ontology-checkers-agent-false-alarms

- 原题：What Does an Ontology Catch? Curated, LLM-Generated and Data-Derived Ontologies as Checkers of LLM Agents over Knowledge Graphs。
- 作者：Michal Orzechowski、Rund Tawfiq、Tomasz Kosciolek。
- [原始摘要与版本记录](https://arxiv.org/abs/2610.37809v1)标注 v1 首次提交为 2026-10-27 18:27:45 UTC。作者 comment 为 Under review；未列会议轨道或录用证据。
- [原始全文](https://arxiv.org/html/2610.37809v1)：§3 检查机制及封闭世界解释，§4 样本和预注册范围，§5 表2—6 错误捕获、误报、重试与原因分析，§6—7 限制和结论。
- 主方向理由：核心研究对象是本体作为知识图谱 Agent 的检查器，其规则一致性、误报及重试后果；直接属于本体、Agent 可靠性和数据治理问题，不是仅在背景提及这些方向。
- 方法核实：比较人工维护、数据推导、模型生成三类本体；数据推导模式要求至少出现五次；主生成模型为 Claude Opus 5.5。同一编译器用于事后检查，另比较本体作为上下文的作用。封闭世界约束与开放世界推理的差异是误报来源之一。
- 数量及结果：确认性结论只针对 UniProt。210 个测试问题、七模型、各三次独立尝试，共 4,410 份答案，3,383 份带可检查查询。真实答案的探索性汇总中，人工本体捕获错误答案 18.9%、误报正确答案 16.8%；数据推导为 8.2%/3.5%；屏蔽标识符生成三本体均值为 5.0%/1.8%。两项分母不同，不是报警精确率。
- 表2 中具体反馈修正 28.3% 的被标记错误答案，也破坏 1.0% 的被标记正确答案。表3 具体反馈与泛化反馈、组合检查相关比较未建立收益；试验预先说明可能不确定，不将不显著解释成绝无效果。
- 边界：人工故障的构造使用数据共现信息，可能有利于数据推导检查；规则可以遗漏语义路径、过滤范围和同类型替换错误。确认性结论受冻结模板和故障集合限制，其他图谱为探索性；私有图谱不可独立复现，生成本体主要来自单个模型。
- 筛选：研究具有独立方法及实验证据；非厂商品牌稿或导购，无色情、赌博、毒品性质内容或引流。图谱生物学背景不转写为医疗建议。

## coverage-aware-longform-rag-context

- 原题：Decompose, Estimate, Select: Coverage-Aware Context Construction for Long-Form RAG。
- 作者：He Tu、Aleena Bosco Kurumthottam、Torsten Suel。
- [原始摘要与版本记录](https://arxiv.org/abs/2610.40314v1)标注 v1 首次提交为 2026-10-29 15:51:46 UTC；未列会议录用证据。
- [原始全文](https://arxiv.org/html/2610.40314v1)：§3 训练与测试集合及分母，§4 管线和生成对照，§5 表1—4 结果，§6 统计及泛化限制。
- 主方向理由：直接研究 RAG 的文档集合选择、信息覆盖和生成阶段证据利用，不按通用检索可服务 RAG 的宽泛理由归类。
- 方法：同一 BM25 前100篇候选池；问题拆十个子问题；覆盖训练双编码器、交叉编码器覆盖估计和最大边际覆盖贪心选择，最终十篇。估计器用 3,000 问的 850,000 个文档—子问题对训练，标签来自模型判断。
- 表1：56 个 TREC RAG 2024 问题；α-nDCG@10 从相关性双编码器的 0.625，到覆盖训练的 0.656，再到显式选择的 0.702；没有报告此表显著性检验，阈值在评估集合选择。另一集合 CRUX-DUC04 为50问。
- 生成条件：Qwen2.5-7B-Instruct；十篇文档，每篇截断250词；输出700 token。表3 的54个共同可评分问题中，回答信息点覆盖率 0.266 对 0.239，差异不显著；另一集合方向反转，不能写成检索覆盖优化稳定改善答案。理想选择器提高检索覆盖，也未稳定提高回答覆盖。
- 表4：反馈版本不使用参考答案、不改变材料。两轮指初稿后的两次额外生成。重要信息点完全支持比例在53个可评分问题上 0.338→0.424，增加0.086；答案信息点覆盖率在54问上 0.266→0.308。相关覆盖收益通过作者列出的多重比较校正。事实句受引用支撑比例在54问上 0.703→0.661，因此不复述“完全没有忠实度代价”的表述。第三轮无进一步收益。
- 边界：TREC 文档—信息点标签对人工评估约69%精确率、90%召回率，模型裁判影响绝对分数；阈值不是独立验证集调参。多轮反馈只在 TREC 评估，另一集合只复核一次反馈；不能声称对所有模型和长文档成立。泄漏参考信息点的方案仅为上界，不当作部署方法。
- 筛选：实质检索与生成研究，无广告、优惠、导购及色情、赌博、毒品性质内容或引流。

## vericua-active-evidence-verification

- 原题：VeriCUA: Verification as Agentic Exploration for Computer-Using Agents。
- 作者：Qiushi Sun、Da Yu、Alexander Knop、Amer Sinha、Lingpeng Kong、Ben Kao、Ravi Kumar、Pritish Kamath。
- [原始摘要与版本记录](https://arxiv.org/abs/2610.40578v1)标注 v1 首次提交为 2026-10-29 17:45:26 UTC；作者 comment 为 Work in progress，没有会议录用证据。
- [原始全文](https://arxiv.org/html/2610.40578v1)：§3 方法与在线/离线规则，§4 表1—2，§5 预算和观察分析，附录B 数据集与实现协议，附录E 限制。
- 主方向理由：核心是 Agent 完成验证、证据来源、可靠性与轨迹标签质量，直接属于 Agent 评测和数据治理相关问题。
- 方法：先观察环境再生成任务要求；利用轨迹、当前界面和持久状态，发现须关联真实读取。执行者自述不单独满足条件。环境只读。在线不确定时弃权；离线多路径未解决时回退到探索前的初始判断，不将所有离线输出描述成完整证据裁决。
- 附录B.1：在线 AndroidWorld 116 次执行、OSWorld 361 次、ScienceBoard 169 次，参考为官方评估器；OSReward 总1,019条人工标签轨迹，困难子集284条；WebArena 715条。主要比较模型为 gemini-3-flash-preview。
- 表1及附录B.4：二分类评分将弃权映射为预测“任务失败”标签，然后与参考标签比较；参考同为失败时计为正确一致，参考成功时才是漏报成功。这里不是将弃权一律视为判断错误或令其准确率为零。因此全样本一致率可以高于实际决策覆盖率，没有这一点上的口径矛盾。按此定义，在线三集合一致率为90.5%、79.5%、86.4%，自动生成验证器为82.4%、75.9%、76.9%。ScienceBoard 假阳性率21.7%→5.4%，分母是参考失败的执行。VeriCUA 决策覆盖82%、78%、70%；OSWorld已决策子集88.7%不得替代全样本79.5%。
- 表2：离线 OSReward 一致率87.2%；困难子集70.4%，所比最强困难子集基线65.7%。WebArena有23%轨迹回退初始判断。所有数字为论文作者报告，不冒充本站复测。
- 边界：每条轨迹数十次工具和模型调用，较单次判断约多一个数量级；在线依赖可访问状态、离线依赖留存证据。部分对照压缩原方法阶段或帧预算，论文另提供匹配预算和消融，不能扩展成任意预算下全面优越。与评估器一致不等于真实任务绝对正确，模型对标签争议的支持不等于独立人工复核。
- 筛选：实质验证方法和多环境实验，不是产品宣传；没有广告导购、色情、赌博、毒品性质内容或相关推广。对状态证据只作公开研究概念说明，不含任何个人设备或账户信息。
