## 1. Meta²：任务内 Agent 干预经验

- 新增 ID：`meta2-task-local-agent-evolution`
- 原标题：Meta²: Precomputing Reusable Knowledge for Online Harness Evolution in Long-Horizon Agents
- 作者：Lingzhi Yuan、Yiguang Cai、Weize Liu、Siqi Yang、Feijiang Han、Yongkyun Lee、Udari Madhushani Sehwag、Furong Huang。
- [版本与摘要](https://arxiv.org/abs/2611.05139v1)：v1 于2026-11-03 16:19:21 UTC提交，未见可核验会议录用证据。
- [原始全文](https://arxiv.org/html/2611.05139v1)：实际阅读§2、§3全部方法、§4实验，附录C的数据与设置、E.1重复波动、F.1限制。
- 主方向分类：直接研究 Agent 的执行控制、经验复用和长任务可靠性，核心是何时、如何及是否干预，而非通用模型性能包装。

### 核验定位与指标

1. §3三种训练运行：无干预者、当前经验引导的干预者、可见训练验证特权信息的干预者。结果形成 act/hold/avoid 的可复用文字知识，不修改基础模型权重。第三种运行被要求不得直接泄漏特权信息，事后泄漏审查不合格轨迹被排除；不能写成没有监督或没有特权训练信号。
2. §3.3与附录C.3：测试时共享经验冻结，验证内容和结果不可见；同一任务内的修改不重置环境或进度，结束后丢弃。后续任务从共同初始配置开始，不能写成测试中持续跨任务自我学习。默认第一步后、之后每五步及最终提交前检查。
3. 附录C.1与表4：Terminal-Bench 2.1训练29、测试60、每题五次＝300次；DeepSWE 1.1训练38、测试75、每题三次＝225次。mean@5/mean@3是每题重复成功率再按题平均，不是best-of或pass@k。
4. §4.2与表1：GPT-5.6-Terra中等推理，Meta² 81.00%/44.44%，起始配置66.33%/34.67%，差14.67/9.77个百分点。附录E.1重复标准差分别0.91/0.77个百分点，非独立跨域总体保证。
5. §4.5：只有在线干预者无知识为74.67%/36.44%；跨任务保留具体修改下降至78.33%/39.11%。DeepSeek变体77.67%使用另建的Meta-Skill，不证明同一知识零样本跨模型迁移。
6. §4.3与表1费用为评测聚合调用费用，非每题成本或现行报价。终端在线64.72美元对起始34.09美元，额外离线110.19美元。§4.4每步检查79.00%低于五步81.00%，更密干预增加费用，不宣传“更便宜更强”而省略比较对象。
7. F.1明确完整轨迹对照不是某次编辑的因果效应；运行可能在介入前已分歧。范围限于可自动验收的终端与软件任务，不推广为开放研究、实体控制或所有任务分布的保证。

## 2. QueryFlow：查询状态与图证据交替更新

- 新增 ID：`queryflow-adaptive-multihop-graph-retrieval`
- 原标题：QueryFlow: Multi-Hop Graph Retrieval with Adaptive Query Evolution
- 作者：Manzong Huang、Chenyang Bu、Yi He、Jiapu Wang、Xindong Wu。
- [摘要与版本](https://arxiv.org/abs/2611.04625v1)：2026-11-03 10:14:30 UTC提交。正文模板出现2027会议名，但无明确录用注释或正式录用证据，按preprint处理。
- [全文](https://arxiv.org/html/2611.04625v1)：实际阅读§3方法、§4.1–4.7实验、§5结论、附录A实验细节、B目标与检索、C读出分析。
- 主方向分类：RAG 多跳证据检索、查询反馈与证据完整性，是方法和实验核心。

### 核验定位与指标

1. §3固定图拓扑、初始问题实体链接和实体—文档关联。冻结编码器表示文本，六层传播中以图状态汇总和循环单元更新共享查询向量，改变起点注入信息及关系特征；不是每层由LLM改写文字，也不是自动补全图结构。
2. 默认用原始查询与最终实体状态评分，聚合所有关联实体的正贡献，按实体文档频率倒数加权；不是只取固定若干实体，也不等于按文档长度归一化。附录A.1训练来自三个数据集各20,000例，共60,000例，以实体监督训练检索与查询控制器。
3. 表5输入记录：2WikiMultiHopQA 1,000、HotpotQA 1,000、MuSiQue 1,003、ConcurrentQA 1,600。文档库分别9,594、9,811、11,666、2,840篇，由选中样例的支持与干扰材料形成，不是全开放网络。评估配对仅4,596个共同可评价问题，与输入记录合计4,603不可混同。
4. 表2宏平均给数据集等权：R@10 81.93%对GFM-RAG76.95%，FR@10 70.38%对61.98%，差4.98/8.40个百分点。R是每题支持文档覆盖比例，FR要求该题整套支持出现。返回十篇不等于传播只访问十个节点。
5. §4.5配对434增、86失、净增348；按题数权重完整召回62.90%→70.47%，增7.57点，不能与数据集宏平均8.40互换。§4.2 MuSiQue普通R@10 61.60低于HippoRAG2的64.42，但FR@10 37.82高于31.11，不宣称所有指标全胜。
6. 所有答案生成用Qwen3.5-9B。表1模型裁判LLM-Acc宏平均69.6%，LinearRAG61.6%；严格EM宏平均50.5%见表6。正文明确模型判分与人工事实核验不同，不能把69.6解释成人工确认的通用准确率。
7. §4.3/4.4在固定学习参数上关闭查询更新，FR@10降至61.78；这是训练后干预，不是固定查询方案另行重训的最优结果。训练只报告一个seed；图抽取/链接、标注目标、有限语料及模型裁判构成本文设置可直接支持的范围，宽泛泛化和重复波动尚不足以确认。限制段将这些作为本次阅读对实验覆盖的判断，未伪称作者做过未报告的测试。

## 3. 事件先后约束的文档检索

- 新增 ID：`event-order-constrained-document-retrieval`

- 作者：Alon Eirew、Lidan Avisar、Kfir Bar、Ido Dagan。
- [摘要与版本](https://arxiv.org/abs/2611.04343v1)：2026-11-03 05:27:23 UTC提交；无可核验会议录用证据。
- [全文](https://arxiv.org/html/2611.04343v1)：实际阅读§3数据与验证、§4方法、§5实验、Limitations、附录A与B。
- 主方向分类：直接研究检索/重排中的事件约束与证据匹配，属于RAG上游检索。题名中的时间线是研究对象的事件顺序，不是会议安排；没有收录任何日历或DDL。

### 核验定位与指标

1. §3.1所有查询事件须被语义支持；时间兼容包含明确顺序、同时发生和无法判断，只有明确逆序才不兼容。保留这一宽松定义，不能称为严格证明全部先后关系。
2. §3.3–3.4从ReliefWeb筛得单事件报告，最终66查询（16开发、50测试），三至十事件、平均六。移除66查询来源文档后6,079篇，15灾害类。全66查询的234相关与400,980无关配对，不是50测试查询的独立计数。
3. GPT-5.2用于查询与标签辅助；证据匹配检查减少无来源引用，不代替真人核验。两作者只核验50对（25正例、25时间困难负例），相互κ=.83、各与模型κ=.80。类别外100对审查无相关，不足以证明类别剪枝绝不漏检。
4. §4离线重排原句，句子内容保持；同一交叉编码器构造事件—句子兼容矩阵。OP保序动态规划与OA自由二分匹配共用匹配分数、查询缺口处罚、覆盖奖励；不匹配查询受罚，文档背景可跳过，参数在开发集选择。
5. §5表1：BM25前250候选覆盖本集合全部相关文档；MiniLM-L12 OP的mAP@10=.50、MRR@10=.70、R@10=.62，OA=.36/.55/.50；整篇直接MiniLM的mAP@10=.32。全部是检索指标，不是生成答案准确率。
6. 表2原句/时间/随机顺序的MiniLM OP mAP@10为.48/.50/.32。原句到时间重排差别不显著，不写成时间预处理普遍必要。时间连接词/指令未稳定改善，仅限已测模型与领域。表1注明每个配置最佳结果，不据此写成大规模多seed稳定平均。
7. 局限：50测试查询、灾害单领域、模型辅助标签与顺序推断、类别候选剪枝；无医学/法律或端到端RAG回答验证。不把研究中的潜在应用场景写成已通过实验。
