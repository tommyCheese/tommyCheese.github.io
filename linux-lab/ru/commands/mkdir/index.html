Справочник команд / mkdir

Часто используется · Организация файлов

mkdir:Создать каталог

Приступайте к свободной практике

Синтаксис

mkdir [-p] [-m Разрешения] Каталог…

Параметры

-p
Создать отсутствующий родительский каталог
-m
Установите трехзначные восьмеричные разрешения

Примеры

mkdir -p projects/demo/src

Использование и поддержка

mkdir -p также может быть успешным, если каталог уже существует.

Практические упражнения

  • Создайте основу для новых проектовОсновные
