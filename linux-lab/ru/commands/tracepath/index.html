Команды по теме

  • ipАдрес запроса и маршрутизация
  • ssПросмотр сокетов и портов прослушивания
  • pingПроверьте подключение к хосту
  • digЗапрос записей DNS
  • nslookupЗапросить адрес хоста
  • curlЗапросите URL или загрузите контент
  • wgetСкачать файл
  • sshВойдите на удаленный компьютер
  • scpКопирование файлов через SSH
  • hostЗапрос DNS
  • tracerouteЗондирование сетевых маршрутов
  • mtrПостоянно наблюдать за маршрутизацией и потерей пакетов.
  • ncТестовое соединение или порт прослушивания
  • socatПодключайте потоки данных к сокетам
  • tcpdumpЗахват сетевых пакетов
  • nmapОбнаружение авторизованного хост-порта
  • ethtoolЗапрос информации о сетевом интерфейсе
  • nmcliУправление соединениями NetworkManager
  • sftpПередавайте файлы в интерактивном режиме через SSH
  • ssh-keygenСгенерировать ключ SSH
  • ssh-copy-idУстановите открытый ключ SSH.
  • opensslПроверьте TLS с сертификатом
