Работайте с терминала Linux или WSL. Сначала создайте временный каталог для упражнений; некоторые параметры macOS отличаются.

Задача

Зайдите в каталог report, укажите полный путь и найдите скрытые файлы.

Подготовить

LAB_DIR=$(mktemp -d)
cd "$LAB_DIR"
mkdir -p report
touch report/.settings report/readme.txt

исследовать

Путь заканчивается на /report; .settings можно найти в каталоге.

Путь к реальному терминалу принадлежит вашему компьютеру; Завершение Tab, скрытые файлы и правила cd проверяются напрямую.

Эталонная операция
cd report
pwd
ls -la

    Работайте с терминала Linux или WSL. Сначала создайте временный каталог для упражнений; некоторые параметры macOS отличаются.

    Задача

    Отфильтруйте developer из списка, извлеките имена, отсортируйте их, удалите дубликаты и сохраните их как developers.txt.

    Подготовить

    LAB_DIR=$(mktemp -d)
cd "$LAB_DIR"
printf 'bob,developer\nalice,designer\ncarol,developer\nbob,developer\n' > users.csv

    исследовать

    developers.txt имеет только bob и carol, две строки в алфавитном порядке.

    Этот вопрос объединяет несколько инструментов в реальном Shell, чтобы проверить, можете ли вы перенести знания об одной команде в полный процесс.

    Эталонная операция
    grep ',developer$' users.csv | cut -d , -f 1 | sort | uniq > developers.txt
cat developers.txt
