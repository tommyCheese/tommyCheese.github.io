Справочник команд / ls

Часто используется · Понимание рабочего пространства

ls: Список файлов и каталогов.

Приступайте к свободной практике

Синтаксис

ls [параметр] [путь]

Параметры

-a
Показать скрытые файлы
-l
Показать разрешения и свойства
-h
Совместимость с переключателем дисплея (размер песочницы имеет значение для обучения)
-R
Список рекурсивно
-d
Показать только сам каталог

Примеры

ls -la

Использование и поддержка

Файлы, начинающиеся с . по умолчанию скрыты. Параметры могут быть объединены в -la.

Практические упражнения

  • Посмотрите, что находится в рабочей областиОсновные
  • Найдите скрытые конфигурацииОсновные
