Справочник команд / tar

Обычно используется · Упаковка и сжатие

tar: Упаковка, просмотр и восстановление архивов.

Приступайте к свободной практике

Синтаксис

tar -[cxt][zv]f архив [каталог -C] [путь…]

Параметры

-c
создавать
-x
Распаковать
-t
список элементов
-f
архивный файл
-z
Обучение тегу gzip
-v
Показать записи
-C
Переключить рабочий каталог архива

Примеры

tar -czf project.tar.gz projects

Использование и поддержка

Архивы песочницы хранят снимки файлов, а не настоящие двоичные файлы tar/gzip.

Практические упражнения

  • Создайте комплект поставки для проектаОсновные
  • Проверьте перед распаковкойОсновные
  • Восстановить в отдельный каталогПродвинутые
  • Упаковать относительный путь из указанного каталогаПродвинутые
  • Точный подбор документов поставкиМастер
