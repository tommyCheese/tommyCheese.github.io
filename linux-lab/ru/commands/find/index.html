Справочник команд / find

Мастер ·Чтение и обработка текста

find: поиск путей по имени или типу.

Приступайте к свободной практике

Синтаксис

find [начальная точка] [условие]

Параметры

-name
Подстановочный знак имени файла
-type
Введите f/d/l
-maxdepth
Максимальное количество слоев
-print
Выходной путь
-delete
Удалить соответствующий путь

Примеры

find . -name "*.log"

Использование и поддержка

Используйте подстановочные знаки в кавычках, чтобы их не расширяли сначала с помощью Shell. -delete следует предварительно просмотреть с помощью -print перед фактическим выполнением.
