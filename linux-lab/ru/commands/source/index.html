source: прочитать сценарий в текущей версии Shell.

Синтаксис

source файл

Примеры

source .profile

Использование и поддержка

Только для справки

Команды по теме

  • echoВывод фрагмента текста
  • printfВывод текста в соответствии с форматом
  • teeВывод и сохранение содержимого конвейера
  • xargsПреобразование входных данных в параметры команды
  • exportУстановить переменные среды
  • envПросмотр переменных среды
  • printenvВыведите значение переменной среды
  • unsetУдалить переменные
  • historyПросмотр истории команд
  • clearОчистите дисплей терминала
  • trueВернуть статус успеха
  • falseСтатус возврата ошибки
  • seqСоздать последовательность чисел
  • sleepПауза на указанное время
  • aliasУстановить псевдоним команды
  • unaliasУдалить псевдоним команды
  • readЧтение переменных из ввода
  • bashЗапустите скрипт Bash
  • shЗапустите сценарий POSIX Shell.
  • commandПоиск команд управления
  • jobsПросмотр текущих вакансий Shell
  • bgВозобновить фоновую работу
  • fgВозобновить работу на переднем плане
  • waitДождитесь завершения дочернего процесса
  • nohupИгнорировать сигнал зависания и запустить
  • timeoutОграничить время выполнения команды
  • watchПериодически отображать результаты команд
  • timeИзмерьте время работы
  • ulimitПросмотр или установка ограничений ресурсов
  • setУстановить поведение Shell
  • trapОбработать выход или сигнал
  • tmuxУправление сеансами терминала
  • screenСохранить терминальную сессию
