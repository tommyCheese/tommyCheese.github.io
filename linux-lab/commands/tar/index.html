常用 · 打包与压缩

tar：打包、查看和恢复归档

语法

tar -[cxt][zv]f 归档 [-C 目录] [路径…]

参数

-c
创建
-x
解包
-t
列出条目
-f
归档文件
-z
教学 gzip 标记
-v
显示条目
-C
切换归档工作目录

示例

tar -czf project.tar.gz projects

使用说明与支持范围

沙盒归档存储的是文件快照，不是真正的 tar/gzip 二进制文件。
