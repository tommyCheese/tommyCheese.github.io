命令手册 / curl

常用 · 排查网络

curl：请求 URL 或下载内容

语法

curl [-IsSfL] [-o 文件] URL

参数

-I
只看响应头
-o
保存到文件
-s / -S / -f / -L
教学兼容开关

示例

curl -o config.json https://example.com/config.json

使用说明与支持范围

仅模拟 https://example.com/health 和 /config.json；不进行真实请求。
