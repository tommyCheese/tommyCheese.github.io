journalctl：查看服务日志

放入自由练习

语法

journalctl [-u nginx] [-n 行数] [-f]

参数

-u
按教学服务查看
-n
末尾行数
-f
教学快照

示例

journalctl -u nginx -n 1

使用说明与支持范围

只展示教学 nginx 日志；真实 -f 会持续跟随。
