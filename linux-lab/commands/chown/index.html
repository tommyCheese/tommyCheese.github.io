chown：修改所有者

语法

chown [-R] 用户[:组] 路径…

参数

-R
递归修改

示例

sudo chown root /etc/app.conf

使用说明与支持范围

教学环境记录所有者字符串，真实系统通常需要管理员权限。

动手练习

  • 交给管理员管理常用
