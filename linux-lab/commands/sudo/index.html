命令手册 / sudo

常用 · 权限与链接

sudo：以管理员身份执行命令

语法

sudo 命令 [参数…]

示例

sudo systemctl start nginx

使用说明与支持范围

本沙盒允许命令模拟管理操作；不模拟密码、用户切换或真实权限拦截。
