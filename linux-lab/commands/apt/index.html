命令手册 / apt

进阶 · 管理服务

apt：管理 Debian/Ubuntu 软件包

语法

apt update | install 包 | remove 包 | search 包 | list --installed

示例

sudo apt install curl

使用说明与支持范围

教学源含 bash、coreutils、curl、wget、nginx、tree、git、vim。其他发行版使用不同包管理器。

动手练习

  • 查询已安装软件包常用
  • 补上缺失的 HTTP 工具进阶
  • 移除不再需要的工具进阶
