常用 · 排查网络

wget：下载文件

语法

wget [-q] [-O 文件] URL

参数

-O
指定文件名，- 表示标准输出
-q
教学静默开关

示例

wget -O health.txt https://example.com/health

使用说明与支持范围

只接受内置教学 URL。
