ping: Check host connectivity

Put in free practice

Syntax

ping [-c times] Host

Options

-c
Send times, sandbox maximum 10

Examples

ping -c 2 example.com

Usage and sandbox support

Only simulates example.com and teaches IP, no real network packets are sent.
