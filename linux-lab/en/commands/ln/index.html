Advanced · Permissions and Links

ln:Create symbolic link

Put in free practice

Syntax

ln -s target link

Options

-s
Create symbolic link

Examples

ln -s projects/notes.txt notes-link

Usage and sandbox support

Relative link targets start from the directory where the link is located. This sandbox does not support hard links.
