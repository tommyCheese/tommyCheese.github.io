        Help
        reset
        Reset the current exercise and return to the original environment.
        undo
        Undoing the previous step can also be done by resetting.
        redo
        Revert the action just undone.
        Enter commands individually in the terminal, or use toolbar buttons.
        Terminal shortcut keys
        Ctrl+A / E
        Move to beginning/end of line
        Ctrl+B / F
        Move left/right one character
        Ctrl+U / K
        Cut the content before/after the cursor
        Ctrl+W
        Cut the word before the cursor (separated by whitespace)
        Ctrl+Y
        Restore cut content
        Ctrl+H / D
        Delete the character / before the cursor
        Ctrl+P / N、↑ / ↓
        Previous/next historical command
        Ctrl+C
        Cancel current input
        Ctrl+L
        Clear the terminal display
        Tab
        Complete command or path
        F6 / Shift+F6
        Switch workspace panes
        macOS also uses the Control key.
        The current exercise history is saved locally and can be exported for backup.
        

        Starting from scratch?
        All playthrough records, mastery and review records, local practice self-assessments, collections, practice files, terminal records, and undo/redo history will be cleared. This action cannot be undone.
        It is recommended to export the backup first and then restart the exercise. The backup data can then be retrieved through "Import Restore".
