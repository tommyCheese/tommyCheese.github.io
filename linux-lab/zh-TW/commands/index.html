任務

進入 report 目錄，顯示完整路徑，並找出隱藏檔案。

準備

LAB_DIR=$(mktemp -d)
cd "$LAB_DIR"
mkdir -p report
touch report/.settings report/readme.txt

檢查

路徑末尾是 /report；目錄中能找到 .settings。

真實終端的路徑屬於你的電腦；Tab 補全、隱藏檔案和 cd 規則可直接驗證。

參考操作
cd report
pwd
ls -la
