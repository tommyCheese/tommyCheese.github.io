進階 · 管理服務

systemctl：查詢與管理 systemd 服務

放入自由練習

語法

systemctl 動作 [服務]

參數

status / is-active
查看狀態
start / stop / restart
控制服務
enable / disable
控制開機啟動
list-units
列出服務

範例

sudo systemctl start nginx

使用說明與支援範圍

模擬 nginx 服務。 enable 和 start 是不同操作；並非所有 Linux 都會使用 systemd。

動手練習

  • 確認服務是否運作常用
  • 服務為什麼沒起來進階
  • 啟動網站服務進階
  • 讓網站開機啟動進階
  • 重新啟動已啟用但停止的服務大師
