# Linux 命令实验室

独立的中文 Linux 命令练习项目。纯静态 HTML、CSS、ES Modules，无第三方运行时依赖；页面、图标和背景资源均位于本目录，可将本目录直接发布到 GitHub Pages 或其他静态托管服务。当前托管入口为 `/linux-lab/`。

## 课程与行为

常用、进阶、大师三个等级，每个等级按现有 10 个专题组织，共 145 个任务、102 个可练命令、237 个手册条目。等级按任务所需的参数、上下文与判断难度划分，同一命令可在多个等级出现；手册按该命令的入门难度归类。文件与目录、文本处理、Shell 协作、权限与链接、归档、系统观察、网络、服务与综合任务各有独立的初始环境。每关围绕一个核心命令，参考流程为 2–5 条命令，包含观察、操作、核对或交付；后续关卡复用已学工具。新关卡开始时弹出目标与命令介绍，初学任务给语法和可选示例，后期及复习默认收起命令介绍。界面文字保持克制：默认只展示任务标题、目标及必要路径；场景与概念说明默认折叠，不重复展示终端欢迎语与操作口号。先学习保存输出与命令连接，再进入文本筛选；专题挑战用于综合迁移。所有关卡均开放教学沙盒支持的命令，允许自由组合工具；按输出、文件内容、路径、权限和系统模型的最终状态判题。通关不区分是否使用提示或重试。

支持教学范围内的管道、输入/输出重定向、追加、引号、变量、`*`/`?` 通配符、`;`、`&&`、`||`，以及历史命令和基础 Tab 补全。所有操作仅改变浏览器内的虚拟状态，没有真实系统执行、外部网络请求或管理员权限。服务、软件包、DNS、HTTP、资源数值均为确定性教学数据。归档是内部文件快照，不是可导出的二进制 tar/gzip。

这是教学解释器，不是完整 Bash。每个命令的手册明确支持的子集及差异；未知命令、参数、命令替换和后台操作会返回中文错误。交互编辑器、远程连接、Docker 等标记为仅供复习。真实系统的权限拦截、信号处理、分页与实时刷新未模拟。文件类型与部分资源大小采用简化模型；正则使用 JavaScript 子集。

完成记录、收藏、当前任务环境、最近 60 段终端输出、提示层级与最近 40 步撤销/重做快照保存在 `localStorage`。当前关卡与自由练习均可在刷新后恢复。切换关卡会加载独立初始环境，已完成进度保留。没有云同步。

主界面底部提供重置、撤销、重做，对应独立输入的 `reset`、`undo`、`redo` 内置命令。重置本身也可撤销；执行新命令清除重做历史。帮助弹窗提供导出备份、导入恢复。新版 JSON 备份包含当前关卡、自由练习工作区、文件与系统状态、终端输出、提示、完成记录、收藏和撤销/重做快照；导入后恢复备份状态。旧版仅进度 JSON 仍按合并进度处理。导入文件上限 30 MB，先验证数据再替换当前工作区。

## 内容维护

- `curriculum.mjs`：章节、任务场景、初始化数据、目标规则、提示、参考解法及中文手册。新增任务时使用稳定 ID，补齐三个提示和参考解法。
- `catalogue.mjs`：扩展命令手册、等级定义与命令默认难度。
- `extra-lessons.mjs`：新增单命令练习及每关的等级、环境与目标。
- `extra-commands.mjs`：新增命令的可执行教学子集。
- `shell.mjs`：确定性解释器、虚拟文件系统及目标判定，不依赖 DOM。新命令必须同步实现、手册范围及有效行为测试。
- `backup.mjs`：备份格式与导入校验，兼容旧版仅进度文件。
- `app.mjs`：界面与路由、进度、收藏、环境可视化。课程地图在对话框中打开，主界面展示右侧终端、当前任务与 Finder 风格的文件系统图标视图、左侧目录概览。拖动分隔手柄可调整终端宽度，最大为工作区可用宽度的 50%；方向键调整，Home/End 到达最小/最大宽度，双击恢复默认。终端和文件内容用 `textContent` 渲染。
- `lab.css`：独立的响应式样式；Linux 主题背景、终端窗口、Finder 风格文件夹与文件图标、关卡地图与简化手册。
- `index.html`：静态页面壳；课程统计由数据更新。新增任务时同步静态 description 与占位统计。

页面内没有博客署名或返回博客的链接。当前 canonical 对应 GitHub Pages 托管地址；独立部署到新地址时更新 `index.html` 中的 canonical。浏览器存储键沿用旧版本，以保留已有练习数据。

```sh
.venv/bin/python tests/check_linux_lab.py
.venv/bin/python tests/check_i18n.py
```

自动测试执行所有 145 关参考解法，同时验证初始环境未完成、不同解法、任务隔离、引号与 UTF-8、变量展开、管道、重定向、条件分支、符号链接、权限、归档恢复、状态序列化与多语言搜索入口。页面发布前还应通过浏览器核对判题、刷新恢复、手册跳转及手机布局。

课程内容为原创中文教学说明，各条手册附文档参考链接。

## 静态内容与搜索收录

运行 `node scripts/build_linux_pages.mjs`，从课程数据生成项目介绍（`guide/`）、课程目录（`courses/`）、命令索引与每条命令手册（`commands/`），以及本项目的 `sitemap.xml`。所有内容直接写入 HTML，不依赖 JavaScript 或练习记录；更新课程后重新生成，并运行 `scripts/build_i18n.py` 更新托管站点总 sitemap。

独立部署时可设置 `LEARN_LINUX_URL=https://example.com/` 后重新生成，更新所有 canonical 与 Open Graph 地址。图标、CSS、导航均使用相对地址。`robots.txt` 必须位于部署站点根目录，其 Sitemap 地址也应改为实际部署地址。

发布后在 Google Search Console 验证实际公开 URL，提交项目 sitemap，并通过 URL 检查核对抓取与收录状态。其他搜索引擎可在各自站长平台提交；仅生成静态页不能保证收录。

## 复习与掌握

`learning.mjs` 管理复习队列、随机专题小测、场景变换和掌握记录。旧版通关数据保留，先作为待复习记录；不会直接折算掌握。今日复习每轮最多 5 题，优先旧进度与到期任务；成功完成的跨日复习按 1、3、7、14、30 天递增，提示和重试不影响间隔。同日重复完成不会增加间隔阶段。复习入口位于底部重置按钮旁，打开独立的 #review 页面。每个等级／专题在关卡地图中有独立 Boss 挑战，完成该等级专题的全部普通关卡后解锁。解锁条件可展开，卡片显示未解锁进度、可挑战、已击败；普通关卡完成时提示新 Boss 解锁。Boss 使用 bosses.mjs 中独立的综合任务：30 个等级／专题场景，在同一工作区同时检查多项目标。常用级完成基本交付，进阶增加证据与保留条件，大师增加恢复验证、精确归档或权限审计；隐藏命令提示，开放沙盒支持的所有命令。difficulty.mjs 加强 37 个普通关卡的参数选择、空格路径、边界记录、递归范围、输出格式与安全约束。新 Boss 不借用普通关卡的掌握记录。旧版在途小测可继续完成。击败记录保存在本地并包含在备份中。

任务与初始化状态同步变换文件／路径和教学 PID，参考解法也同步变换；所有关卡、复习和 Boss 挑战均不限制命令，命令补全展示全部可练习命令；通关按输出或状态目标判断，允许替代解法。复制题必须保留原文件。在不同日期成功完成，且有一次复习／小测后标记已掌握。提示最高层级和本次错误不随 undo 或 reset 清除；新一轮训练重新记录。刷新恢复本轮队列、变体、提示与撤销历史，导入导出包含掌握记录与本地任务自评。

`terminal-labs.mjs` 为 10 个专题提供可选 Linux/WSL 本地任务、准备、验收、参考操作和沙盒差异。文件任务在用户主动创建的临时目录内进行；系统、网络与服务任务以观察为主。本地完成只能自评，不计为自动验证的掌握。网站不执行本地脚本，也不上报学习记录。

`task-copy.mjs` 汇总中文任务文案修正与目标参考内容。任务要求直接展示在标题下方，知识说明与较长的目标输出／文件内容／包内路径按需展开；普通练习、变体复习和 Boss 使用相同显示规则。

## 入门路线与练习复盘

`practice-support.mjs` 提供复用现有关卡的 24 关、四阶段入门路线（`#starter/关卡ID`，建立方向感 → 整理与交付 → 保存与筛选 → 组合与迁移）。新用户默认从入门路线开始；关卡地图中的“入门路线”可自由选择，完成记录与原专题共享。上一关、下一关和 Ctrl/Command+Enter 按路线顺序切换，完成最后一关可选择专题继续。路线随本地保存与备份恢复；旧版备份不受影响。

执行命令后，未达成目标旁显示具体差异，目标与当前内容按需展开。文件、目录、权限、链接、归档、输出和系统状态均根据实际目标判断，初始页面不堆叠未完成提示。通关后可展开“命令解释与其他解法”，展示最近 12 条操作，按中文手册逐段解释最后一步命令及参数、管道、重定向；不明确的参数指向手册，不生成推测说明。参考或替代解法展示前会在该关初始状态的独立沙盒中验证，最多三种，复习和 Boss 使用实际变体环境；验证不改变用户文件、记录或终端。

## 任务编排与学习节奏

通关时显示奶酪徽章、短暂庆祝动画、本关收获与下一关预告；支持关闭后继续探索，以及 Ctrl/Command+Enter 继续。减少动态效果偏好下省略庆祝动画。解法对照并排展示当前环境保留的操作历史（最多 200 次输入）和已验证参考路径中输入行数较少的一份，高亮不同写法；比较的是输入行数，不是管道内的命令数，也不宣称数学意义上的最优解。提示、重试与额外观察不影响通关评价。

`lesson-flow.mjs` 将全部 145 关扩展为观察／操作与核对／交付两个阶段，参考流程 2–5 条命令。前期导航与阅读使用两处观察，不提前加入报告目录、管道和重定向；后期结合备份后清理、复制交付、归档恢复、过滤观察报告等目标。复习、Boss、不同解法与备份继续共用原来的稳定关卡 ID。已通关记录保留；旧的在途环境可以继续做新增目标。每关开始弹出介绍，恢复已有终端记录时不重复打断；复习和 Boss 默认收起工具提示。

入门路线按工具依赖重排为四组各 6 关；专题仍按常用、进阶、大师提供自由选择。到期复习先选最早的知识缺口，再交错不同专题；同一专题不足时顺序补足，不提前拉入尚未到期的任务。间隔维持 1、3、7、14、30 天的产品默认值，并非声称这些天数适合所有学习者。

设计依据：[Dunlosky 等学习技术综述](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html) 与 [EEF 认知科学证据综述](https://educationendowmentfoundation.org.uk/news/new-what-do-we-really-know-about-cognitive-science-in-the-classroom-eef-publishes-new-review-of-the-evidence)。主动回忆、间隔练习、示例与支架渐退、按目标给差异反馈用于指导编排；交错练习在基础建立后使用。它们为设计提供依据，网站本身的学习效果尚未通过用户实验验证。
