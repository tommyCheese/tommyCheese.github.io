# Linux 命令实验室

独立的中文 Linux 命令练习项目。纯静态 HTML、CSS、ES Modules，无第三方运行时依赖；页面、图标和背景资源均位于本目录，可将本目录直接发布到 GitHub Pages 或其他静态托管服务。当前托管入口为 `/linux-lab/`。

## 课程与行为

常用、进阶、大师三个等级，每个等级按现有 10 个专题组织，共 132 个任务、102 个可练命令、237 个手册条目。等级按任务所需的参数、上下文与判断难度划分，同一命令可在多个等级出现；手册按该命令的入门难度归类。文件与目录、文本处理、Shell 协作、权限与链接、归档、系统观察、网络、服务与综合任务各有独立的初始环境。每关围绕一个核心命令，参考流程为 2–5 条命令，包含观察、操作、核对或交付；后续关卡复用已学工具。新关卡开始时弹出简短的知识介绍与基本语法，关闭后聚焦终端；目标栏顶部的介绍按钮可重新打开。任务目标只在右侧目标清单中显示，Boss 使用独立开场引导；复习直接进入任务。界面文字保持克制：默认只展示任务标题、目标及必要路径；概念说明放在开场介绍中，不重复展示终端欢迎语与操作口号。先学习保存输出与命令连接，再进入文本筛选；专题挑战用于综合迁移。所有关卡均开放教学沙盒支持的命令，允许自由组合工具；按输出、文件内容、路径、权限和系统模型的最终状态判题。通关不区分是否使用提示或重试。

支持教学范围内的管道、输入/输出重定向、追加、引号、变量、`*`/`?` 通配符、`;`、`&&`、`||`，以及历史命令和基础 Tab 补全。所有操作仅改变浏览器内的虚拟状态，没有真实系统执行、外部网络请求或管理员权限。判题同时核对结果与实际数据来源，输出、文件和管道保留来源记录，支持等价的读取与处理方式；文本写入任务仍按其目标检查。服务、软件包、DNS、HTTP、资源数值均为确定性教学数据。归档是内部文件快照，不是可导出的二进制 tar/gzip。

终端提供常用 Readline 风格快捷键：Ctrl+A/E、B/F 移动光标，Ctrl+U/K/W 剪切，Ctrl+Y 恢复剪切，Ctrl+H/D 删除字符，Ctrl+P/N 浏览历史，Ctrl+C 取消输入，Ctrl+L 清屏。快捷键只作用于命令输入框，保留输入法与 Ctrl+Shift+C 等组合；帮助中提供完整列表。

这是教学解释器，不是完整 Bash。每个命令的手册明确支持的子集及差异；未知命令、参数、命令替换和后台操作会返回中文错误。交互编辑器、远程连接、Docker 等标记为仅供复习。真实系统的权限拦截、信号处理、分页与实时刷新未模拟。文件类型与部分资源大小采用简化模型；正则使用 JavaScript 子集。

完成记录、收藏、当前任务环境、最近 60 段终端输出、提示层级与最近 40 步撤销/重做快照保存在 `localStorage`。当前关卡与自由练习均可在刷新后恢复。切换关卡会加载独立初始环境，已完成进度保留。没有云同步。

主界面底部提供重置、撤销、重做，对应独立输入的 `reset`、`undo`、`redo` 内置命令。重置本身也可撤销；执行新命令清除重做历史。帮助弹窗提供导出备份、导入恢复。新版 JSON 备份包含当前关卡、自由练习工作区、文件与系统状态、终端输出、提示、完成记录、收藏和撤销/重做快照；导入后恢复备份状态。旧版仅进度 JSON 仍按合并进度处理。导入文件上限 30 MB，先验证数据再替换当前工作区。

## 内容维护

- `curriculum.mjs`：章节、任务场景、初始化数据、目标规则、提示、参考解法及中文手册。新增任务时使用稳定 ID，补齐三个提示和参考解法。
- `catalogue.mjs`：扩展命令手册、等级定义与命令默认难度。
- `extra-lessons.mjs`：新增单命令练习及每关的等级、环境与目标。
- `extra-commands.mjs`：新增命令的可执行教学子集。
- `shell.mjs`：确定性解释器、虚拟文件系统及目标判定，不依赖 DOM。新命令必须同步实现、手册范围及有效行为测试。
- `backup.mjs`：备份格式与导入校验，兼容旧版仅进度文件。
- `app.mjs`：界面与路由、进度、收藏、环境可视化。课程地图在对话框中打开，主界面展示右侧终端、当前任务与 Finder 风格的文件系统图标视图、左侧目录概览。拖动分隔手柄可调整终端宽度，最大为工作区可用宽度的 50%；方向键调整，Home/End 到达最小/最大宽度，双击恢复默认。终端和文件内容用 `textContent` 渲染。
- `lab.css`：独立的响应式样式；Linux 主题背景、终端窗口、Finder 风格文件夹与文件图标、关卡地图与简化手册。
- `index.html`：静态页面壳；课程统计由数据更新。新增任务时同步静态 description 与占位统计。

页面内没有博客署名或返回博客的链接。当前 canonical 对应 GitHub Pages 托管地址；独立部署到新地址时更新 `index.html` 中的 canonical。浏览器存储键沿用旧版本，以保留已有练习数据。

## 复习与掌握

`learning.mjs` 按稳定关卡 ID 追踪一个主要目标技能，同一技能的回忆题、变式题和组合题共用记录；`completed` 独立保存永久通关进度。辅助命令与 Boss 不会在缺少专项证据时获得技能加分。每项技能新增带版本的 `memory`：难度、半衰期、复习锚点、到期时间及最近 120 次结果／实际间隔／预测回忆率／有效练习秒数。旧数据按原间隔估算初始半衰期，保留计数和到期日期，不伪造旧练习事件。旧版本在途复习继续使用原变式，后续新轮次启用新题型。

调度使用 `p=2^(-elapsed/halfLife)` 估计保持情况，跨本地日期且至少相隔 20 小时的成功才增长半衰期；增长考虑真实间隔和当前难度，下次间隔限制为 1–60 天。同日重做不延长到期时间。“暂时不会”降低记忆强度并安排次日巩固，立即看解法后完成不算跨天提取。提示、查手册、语法错误、重试不降级；跳过、离开、刷新不写入失败。只有有效跨天表现与当前到期状态影响“保持良好”等动态状态，不再跨两天就永久标记已掌握。有效练习用时仅作记录，后台、失焦、弹窗及超过一分钟的无交互停留不计时；用时不影响题量、记忆分数或通关判定。

今日复习列出全部到期技能，不设置时长或题量上限，也不拉入尚未到期任务。按预计保持情况排序，再交错专题。页面只保留一个主按钮：有保存进度时显示“继续复习”，否则显示“开始复习”；下方按顺序预览任务，任务清单和技能记录不提供单题入口。练习中可以跳过或随时“暂停复习”，下次从原题接着做；暂停保留工作区、任务变式、判题结果、提示和撤销记录，切换普通练习或自由练习也不会覆盖。做完全部任务才结束本次复习，摘要统计完成和待巩固项。刷新、语言切换与导入导出均保留复习进度和记忆记录。旧版在途复习仍可继续，其时长字段不再限制后续任务。

`review-variants.mjs` 为新复习使用三组轮换条件，覆盖路径起点、相对／绝对定位、输入识别、备份后清理、首尾行范围、大小写与字段边界、排序方向与去重、分隔符、步长、缩进、权限、归档恢复、进程与服务、系统字段提取等。每项技能按既有练习次数轮换条件，批次与数据另外变化；原件、备份、相似名称、目录深度等作为保留条件，要求观察、处理与核对。专门的复杂链接、字节格式、下载等任务保留已验证的原有约束，并沿用路径与安全数据变换；不为固定系统事实编造随机值。提示依次提供判断依据、核对思路与可执行参考流程，默认收起。任务目标只展示一次。

关卡标题、命令和稳定技能 ID 与闯关一致，复习列表不再另起技能名。新复习使用 `reviewVersion:2`，在开始时固定每项技能的轮换序号 `rounds`，与工作区一起保存；刷新、重置当前题、暂停、切换语言与备份恢复不重新抽题，之后更新的练习记录也不影响当前题。`review-exercises.mjs` 保留旧版本的 20 个专项模板，旧的在途题继续原样完成。测试覆盖全部 132 关的五个轮次与三个批次、四种外语的三组条件、错误解法、初始状态未完成以及新旧备份。

这是借鉴 [SSP-MMC](https://github.com/maimemo/SSP-MMC) 思路的保守自适应调度，参数是待验证的产品默认值，并非在 Linux 数据上拟合的模型，也不宣称 SSP 最优或特定效率提升。记录实际间隔、延迟提取结果和有效耗时，为后续比较 7／30 天保持情况与时间成本留出证据；历史有上限，不能替代长期研究数据集。

每个等级／专题在关卡地图中有独立 Boss 挑战，完成该等级专题的全部普通关卡后解锁；常用级综合任务不再设置重复的普通练习，其 Boss 在完成该等级全部普通关卡后解锁。解锁条件可展开，卡片显示未解锁进度、可挑战、已击败；普通关卡完成时提示新 Boss 解锁。Boss 使用 bosses.mjs 中独立的综合任务：30 个等级／专题场景，在同一工作区同时检查多项目标。常用级完成基本交付，进阶增加证据与保留条件，大师增加恢复验证、精确归档或权限审计；隐藏命令提示，开放沙盒支持的所有命令。difficulty.mjs 加强普通关卡的参数选择、空格路径、边界记录、递归范围、输出格式与安全约束。新 Boss 不借用普通关卡的掌握记录。旧版在途小测可继续完成。击败记录保存在本地并包含在备份中。

`varyExercise` 同时变换初始文件系统、进程 PID、目标路径、文件内容、提示与参考解法。复制题必须保留源文件。`validLearning`、`validExercise` 与 `validAttempt` 验证导入的记忆状态、轮次、计时和再学习状态；旧版 1／2 备份继续可读，新字段随现有版本 2 备份保存。

`terminal-labs.mjs` 在命令参考手册的 10 个专题下提供可选 Linux/WSL 本地任务、准备、验收、参考操作和沙盒差异。文件任务在用户主动创建的临时目录内进行；系统、网络与服务任务以观察为主。本地完成只能自评，不计为自动验证的掌握。网站不执行本地脚本，也不上报学习记录。

`task-copy.mjs` 汇总中文任务文案修正与目标参考内容。任务要求直接展示在标题下方，知识说明与较长的目标输出／文件内容／包内路径按需展开；普通练习、变体复习和 Boss 使用相同显示规则。

## 入门路线与练习复盘

`practice-support.mjs` 提供复用现有关卡的 24 关、四阶段入门路线（`#starter/关卡ID`，建立方向感 → 整理与交付 → 保存与筛选 → 组合与迁移）。新用户默认从入门路线开始；关卡地图中的“入门路线”可自由选择，完成记录与原专题共享。上一关、下一关和 Ctrl/Command+Enter 按路线顺序切换，完成最后一关可选择专题继续。路线随本地保存与备份恢复；旧版备份不受影响。

执行命令后，未达成目标旁显示具体差异，目标与当前内容按需展开。文件、目录、权限、链接、归档、输出和系统状态均根据实际目标判断，初始页面不堆叠未完成提示。通关后可展开“命令解释与其他解法”，展示最近 12 条操作，按中文手册逐段解释最后一步命令及参数、管道、重定向；不明确的参数指向手册，不生成推测说明。参考或替代解法展示前会在该关初始状态的独立沙盒中验证，最多三种，复习和 Boss 使用实际变体环境；验证不改变用户文件、记录或终端。

## 任务编排与学习节奏

通关时显示奶酪徽章、短暂庆祝动画、本关收获与下一关预告；支持关闭后继续探索，以及 Ctrl/Command+Enter 继续。减少动态效果偏好下省略庆祝动画。解法对照并排展示当前环境保留的操作历史（最多 200 次输入）和已验证参考路径中输入行数较少的一份，高亮不同写法；比较的是输入行数，不是管道内的命令数，也不宣称数学意义上的最优解。提示、重试与额外观察不影响通关评价。

`guidance.mjs` 从当前文件、目录、权限、输出与目标差距生成两级提示，第三层提供参考路径；提示会随操作更新。解法对照补充路径、管道、tee 与额外观察的思路区别，下一关预告显示下一关名称。文件变化在对应目录高亮，位置、权限、服务与移除结果提供简短状态标签；支持的读取管道可展开每一步的中间输出，所有计算在隔离副本中完成。

右侧面板统一展示标题、唯一的目标清单、命令介绍和提示，可通过顶部按钮隐藏或展开；所有操作直接在中间终端完成。提示可隐藏／显示，并用上一条、下一条及页码来回查看三层内容，隐藏不改变当前提示层级，显示状态随本地练习与备份保存。提示按当前状态与目标差距更新线索。

文件任务取消固定 delivery.txt 的重复复制，改为识别同名文件、处理含空格路径、区分追加与覆盖、读回内容或核对元信息；状态修改任务直接查询结果。备份清理、归档恢复和有实际筛选条件的报告继续保留。需要读回的备份或报告，须在对应文件存在后观察输出；旧版本会补齐新目标，保留已完成记录、用户文件和有效输出记录。

`lesson-flow.mjs` 将全部 132 关扩展为观察／操作与核对／交付两个阶段，参考流程 2–5 条命令。前期导航与阅读使用两处观察，不提前加入报告目录、管道和重定向；后期结合备份后清理、状态核对、归档恢复、过滤观察报告等目标。复习、Boss、不同解法与备份继续共用原来的稳定关卡 ID。已通关记录保留；旧的在途环境可以继续做新增目标。每关开始弹出介绍，恢复已有终端记录时不重复打断；复习和 Boss 默认收起工具提示。

入门路线按工具依赖重排为四组各 6 关；专题仍按常用、进阶、大师提供自由选择。到期复习先选最早的知识缺口，再交错不同专题；同一专题不足时顺序补足，不提前拉入尚未到期的任务。复习间隔按上述记忆状态与真实间隔调整，参数需要后续数据验证。

设计依据：[Dunlosky 等学习技术综述](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html) 与 [EEF 认知科学证据综述](https://educationendowmentfoundation.org.uk/news/new-what-do-we-really-know-about-cognitive-science-in-the-classroom-eef-publishes-new-review-of-the-evidence)。主动回忆、间隔练习、示例与支架渐退、按目标给差异反馈用于指导编排；交错练习在基础建立后使用。它们为设计提供依据，网站本身的学习效果尚未通过用户实验验证。

## 多语言

与博客一致提供 `zh-CN`、`en`、`ja`、`ru`、`zh-TW` 五种语言。简体中文入口为 `/linux-lab/`，其他语言使用 `/linux-lab/en/` 等路径；语言选择保留当前关卡、查询参数和练习记录，并共享博客的 `site-language` 偏好。

`locales/*.json` 保存界面、课程、提示和手册的翻译；`locales/source.json` 是覆盖检查清单。新增文案时同步补齐四个翻译词表。`content-i18n.mjs` 将 README、任务 brief 等模拟文件中的教学说明及压缩快照说明同步为当前语言，并更新对应的内容和文件大小判题目标。切换语言或导入备份时，也会迁移已有文件、归档、终端记录和撤销／重做快照中的教学说明。命令、示例文件名、真实路径、结构化练习数据和用户自写内容保持不变；仅完整匹配课程提供的说明行才会翻译。所有词表随站点发布，访客浏览时不调用外部翻译服务。

更新课程后依次运行：

```sh
node scripts/build_linux_pages.mjs
.venv/bin/python scripts/build_linux_i18n.py
.venv/bin/python scripts/build_i18n.py
node --test tests/linux-*.test.mjs
.venv/bin/python tests/check_linux_pages.py
.venv/bin/python tests/check_i18n.py
```

多语言构建生成静态手册、课程目录和独立入口，为每页设置 canonical、五语言 `hreflang` 与 `x-default`，并更新 Linux Lab 和全站 sitemap。博客不同语言版本的 Linux Lab 导航分别指向对应语言。

## 键盘操作

`ui-keys.mjs` 统一弹窗和工作区的键盘行为。Enter 在介绍正文中执行当前主要动作，焦点已在按钮、链接、输入框、下拉框和折叠标题时保留原生行为；Esc 只关闭最上层弹窗，关闭后回到打开它的控件。重启确认正文中的 Enter 默认取消，必须明确聚焦确认按钮才能清空记录。输入法组字与按键长按不跨越弹窗连续触发。

关卡地图自动聚焦搜索框，Enter 进入首个匹配关卡，↓ 移入关卡列表，方向键按可见位置选关；等级、文件／系统页签与提示页码支持方向键。F6／Shift+F6 在文件、终端和目标窗格间切换，终端保留 Tab 补全、Shift+Tab 离开输入框、Ctrl／Command+Enter 下一关。关键确认按钮只附小号 Enter／Esc 文本，不增加独立提示栏。

## Linux 系统目录

`linux-filesystem.mjs` 补齐常见 Linux 目录、系统配置、程序文件、设备与 proc/sys 示例。`which` 按 PATH 查询存在且有执行位的文件，`type` 优先识别内建命令；支持通过绝对程序路径调用教学命令。旧会话与撤销快照在载入时按版本补齐，保留用户已有文件。系统内容为固定教学数据，不运行宿主程序或模拟真实内核。

## 目标说明校验

`task-copy.mjs` 在普通关、Boss 和复习任务组装后统一补全目标说明：明确文件、目录、权限、链接、服务及输出要求，区分保留原件与创建交付物；内容对照显示精确文本和末尾换行要求，归档对照同时包含内部路径与文件内容。路径变式沿用这些语义，撤销恢复重新计算目标并使用当前说明。`linux-task-copy.test.mjs` 覆盖全部关卡、三个复习批次、Boss 变式及多语言目标文本。

## 开场术语说明

`terminology.mjs` 在关卡介绍中提供与当前任务相关的简短定义，覆盖重定向、管道、路径、权限、进程、网络等概念。语法说明按参考命令的词法结构选择，区分真正的操作符与引号中的普通文本；每个概念只在当前课程顺序中首次涉及它的关卡介绍，新手路线按自己的顺序计算；后续关卡、复习与 Boss 不再重复术语定义。首次关卡的介绍可重复打开，刷新或切换语言不会改变归属。定义同步到五种语言，目标、判题与命令使用范围保持原有规则。介绍弹窗从顶部开始阅读，Enter 开始练习，关闭后回到终端。

重复用法的 13 个普通关卡已移除，保留教授新参数或新概念的练习。`retired-lessons.mjs` 将旧书签导向保留关卡，并在读取本地进度与备份时移除废弃记录及不兼容的在途环境，保留其余掌握、上次答案与 Boss 记录。
