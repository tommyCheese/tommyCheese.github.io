      ヘルプ
      reset
      現在のエクササイズをリセットし、元の環境に戻ります。
      undo
      前のステップを元に戻すには、リセットすることもできます。
      redo
      元に戻したばかりのアクションを元に戻します。
      ターミナルにコマンドを個別に入力するか、ツールバーのボタンを使用します。
      ターミナルのショートカットキー
      Ctrl+A / E
      行頭/行末に移動
      Ctrl+B / F
      1文字ずつ左右に移動
      Ctrl+U / K
      カーソルの前後のコンテンツを切り取る
      Ctrl+W
      カーソルの前の単語を切り取ります (空白で区切られています)。
      Ctrl+Y
      カットされたコンテンツを復元する
      Ctrl+H / D
      カーソル前の文字 / を削除します
      Ctrl+P / N、↑ / ↓
      前/次の履歴コマンド
      Ctrl+C
      現在の入力をキャンセルします
      Ctrl+L
      端末表示をクリアする
      Tab
      完全なコマンドまたはパス
      F6 / Shift+F6
      作業ペインを切り替え
      macOS は Control キーも使用します。
      現在の運動履歴はローカルに保存され、バックアップのためにエクスポートできます。
      

      ゼロから始めますか？
      すべてのプレイスルー記録、マスタリーおよびレビュー記録、ローカル練習自己評価、コレクション、練習ファイル、端末記録、および元に戻す/やり直し履歴がクリアされます。この操作は元に戻すことができません。
      最初にバックアップをエクスポートしてから、演習を再開することをお勧めします。バックアップ データは、「インポート リストア」を通じて取得できます。
