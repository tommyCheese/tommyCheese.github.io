よく使われる・包装と圧縮

unzip: ZIP アーカイブを解凍します。

構文

unzip archive.zip [-d ディレクトリ]

オプション

-d
ターゲットディレクトリを指定する
-l
最初にコンテンツをリストする

使用例

unzip project.zip -d restored

使い方と対応範囲

確認のために、まずアーカイブの内容とターゲットのパスを確認します。

このコマンドは参照とレビュー用であり、シミュレーション ターミナルには対応する演習がまだ提供されていません。
