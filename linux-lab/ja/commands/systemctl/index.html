コマンドリファレンス / systemctl

高度な管理サービス

systemctl: クエリおよび管理 systemd サービス

自由練習に参加する

構文

systemctl アクション [サービス]

オプション

status / is-active
ステータスの表示
start / stop / restart
制御サービス
enable / disable
制御起動
list-units
リストサービス

使用例

sudo systemctl start nginx

使い方と対応範囲

nginx サービスをモックします。 enable と start は異なる操作です。すべての Linux が systemd を使用するわけではありません。

実践的な演習

  • サービスが実行されているかどうかを確認する基本
  • サービスが起動しないのはなぜですか?応用
  • ウェブサイトサービス開始応用
  • ウェブサイトを立ち上げてみましょう応用
  • デリバリーの課題② サービス開始応用
  • デリバリーチャレンジ③ 立ち上げ応用
  • 有効になっているが停止しているサービスを再起動する上級
