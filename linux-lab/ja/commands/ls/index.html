コマンドリファレンス / ls

よく使用される · ワークスペースについて理解する

ls: ファイルとディレクトリをリストします。

自由練習に参加する

構文

ls [パラメータ] [パス]

オプション

-a
隠しファイルを表示する
-l
権限とプロパティを表示する
-h
表示切替に対応（サンドボックスサイズはティーチング値）
-R
再帰的にリストする
-d
ディレクトリ自体のみを表示する

使用例

ls -la

使い方と対応範囲

で始まるファイル。デフォルトでは非表示になっています。パラメータは -la に結合できます。

実践的な演習

  • ワークスペースの内容を確認する基本
  • 隠された設定を見つける基本
